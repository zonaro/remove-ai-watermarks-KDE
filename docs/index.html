Recursos

Tudo o que você precisa para limpar imagens de IA, sem sair do seu gerenciador de arquivos.

🔍

Identificar

Analisa a imagem e gera um relatório completo em <nome>_ai_analysis.txt, aberto automaticamente no seu editor.

🧹

Remover marca visível

Detecta e remove marcas visíveis conhecidas (Gemini, Doubao, Jimeng, Qwen, Kling e mais).

🏷️

Remover metadados

Limpa metadados de IA (C2PA, EXIF, parâmetros de geração) que identificam a imagem como gerada.

⚡

Remover tudo

Pipeline completo: marca visível + metadados + marca invisível, em uma única operação.

📁

Processar em lote

Selecione uma pasta ou várias imagens e limpe todas de uma vez. Pula automaticamente arquivos já limpos.

🌍

Instalação

Primeiro instale o CLI remove-ai-watermarks, depois rode o instalador.

1

Instale o CLI

O projeto é um front-end para o remove-ai-watermarks — ele precisa estar no seu PATH.

uv tool install --force "remove-ai-watermarks[visible]"
2

Instale os menus de contexto

O instalador detecta seu ambiente e instala em todos os gerenciadores compatíveis.

curl -fsSL https://raw.githubusercontent.com/zonaro/remove-ai-watermarks-contextmenu/main/install.sh | bash

Para instalar em todos os gerenciadores suportados, mesmo os não detectados:

curl -fsSL https://raw.githubusercontent.com/zonaro/remove-ai-watermarks-contextmenu/main/install.sh | bash -s -- --all
3

Reinicie o gerenciador

Para o menu aparecer, reinicie o gerenciador de arquivos uma vez.

killall dolphin      # KDE
nautilus -q          # GNOME
thunar -q            # XFCE (ou faça logout/login)
nemo -q              # Cinnamon
caja -q              # MATE

Como usar

Clique com o botão direito em uma imagem, pasta ou seleção múltipla.

🖼️ Imagem única

  • Identificar
  • Remover marca visível
  • Remover metadados de IA
  • Remover tudo

📚 Múltiplas imagens

  • Processar em lote (visible)

📁 Pasta

  • Processar em lote (visible)

💡 Os arquivos limpos são salvos ao lado do original como <nome>_ai_cleaned.<ext>. O modo Identificar gera <nome>_ai_analysis.txt e abre no editor padrão.

Desinstalação

Remove todos os menus de contexto e o script auxiliar — sem tocar nas suas imagens limpas.

curl -fsSL https://raw.githubusercontent.com/zonaro/remove-ai-watermarks-contextmenu/main/uninstall.sh | bash

A desinstalação não remove o CLI remove-ai-watermarks nem os arquivos _ai_cleaned que você gerou.
